Read https://nhajela.github.io/openyam-playground/spec/v1.md and help me design a playable for the OpenYAM arm: <your idea>. Build the simulator from the spec so I can see it, validate it, then give me the JSON and an offline viewer link.

What happens at the lab

  1. The station reads your QR (or JSON file) and checks the version.
  2. It re-validates the motion with the lab's own Python validator: joint limits, speed and acceleration caps, a 60 s limit, and where the gripper tip goes.
  3. It previews the motion on screen for the operator.
  4. A human clears the space around the arm and presses Play. They may refuse anything, for any reason.

This viewer runs a faithful port of that validator, so “passes here” should mean “passes there”, but the lab's check is the one that counts.

Versioning promise

  • Every playable says "format": "openyam-playable" and "version": "1.0".
  • Any 1.x is accepted. Minor versions only add optional fields; unknown fields are ignored.
  • A different major version (2.0, …) is refused rather than guessed at.
  • No version at all? Read as a legacy 1.0 playable, with a note.
  • Optional "caps": "default" (0.3 rad/s, 1.0 rad/s²) or "dance" (0.6 rad/s, 2.0 rad/s²).

spec/v1.md is frozen; spec/latest.md tracks the newest 1.x.
